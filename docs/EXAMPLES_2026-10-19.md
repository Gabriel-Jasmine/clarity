- Keep question → visible essential guidance/context → optional Example → answer. Existing answer starter and unknown/conditional controls retain their position and behavior.
- Typing retains the existing field and open disclosure DOM instance. Page/branch rerenders start closed again. Disclosure state is not added to decision data, completion logic or exports.

## Implementation and compatibility

`exampleDisclosure` in app.js renders the component for all existing examples, including the Reversibility writer. Dynamic text is still escaped by its caller. Old page-specific example style rules are removed in favor of `.example-disclosure` and `.example-content`. The opening field now has a separate native label rather than nesting an interactive disclosure inside its answer label. Optional example bodies are removed from answer `aria-describedby`; essential guidance and the answer starter remain associated. The standalone component showcase contains closed specimens and one explicitly open design specimen, not a production default.

Existing example text is retained. The illustrative higher-paying-job/relocation story shown in the review mock is not adopted by this display change. Questions, assessments, conditional meanings, saved answers/history, sources, reviewed states, capture metadata, storage key and export schema 2 remain unchanged. Shared stylesheet and affected script query versions are updated for cache refresh.
